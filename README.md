# 🔥 Industrial Defect Detection System

AI-powered computer vision system for manufacturing quality control using YOLOv8 and deep learning.

## 🚀 Features
- Real-time defect detection with YOLOv8 (CPU-optimized)
- Image upload and camera capture support
- Interactive dashboard with analytics
- Detection history with export capabilities
- Gemini API integration for detailed analysis
- Dark/Light theme support

## 📋 Requirements
- Python 3.10+
- Node.js 18+
- 8GB RAM minimum
- CPU (GPU optional)
